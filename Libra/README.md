# Libra

トニーシュワルツの4つのエネルギー(身体・感情・思考・精神)それぞれについて、気持ち(positive / negative)とエネルギー量(high / low)を質問し、どのゾーンにいるかをMarkdownのリストで表示するCLI。


| | high | low |
|---|---|---|
| positive | パフォーマンス活動ゾーン | リニューアルゾーン |
| negative | サバイバルゾーン | バーンアウトゾーン |

## HOW TO USE

リポジトリのルートで実行する。

```shell
cd ~/shiroMadoushi/
cabal run libra
```
